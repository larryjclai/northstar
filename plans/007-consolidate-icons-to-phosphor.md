## Why this matters

The app ships **two** icon libraries. Phosphor (`@phosphor-icons/react`) is the primary
set — there is a curated registry of ~60 icons at `src/lib/icons.tsx` and it is used
throughout the product UI. `lucide-react` is used in only **6 files** (5 generated
shadcn `ui/` components plus 2 `coss/` components) for a handful of chevrons and glyphs.
Both libraries are bundled into the same `icons` manual chunk (`vite.config.ts:50`).
Removing lucide eliminates a redundant dependency and icon tree, shrinks that chunk, and
gives the UI a single, consistent icon vocabulary. The replacements are all common
glyphs with direct Phosphor equivalents.

## Current state

The complete set of `lucide-react` usages (verified at `9115a2b5`):

| File | lucide import | Phosphor replacement |
|------|---------------|----------------------|
| `src/components/ui/calendar.tsx:12` | `ChevronLeftIcon, ChevronRightIcon, ChevronDownIcon` | `CaretLeft, CaretRight, CaretDown` |
| `src/components/ui/command.tsx:16` | `SearchIcon, CheckIcon` | `MagnifyingGlass, Check` |
| `src/components/ui/date-picker.tsx:4` | `CalendarIcon` | `CalendarBlank` |
| `src/components/ui/dialog.tsx:6` | `XIcon` | `X` |
| `src/components/coss/spinner.tsx:1` | `Loader2Icon` | `CircleNotch` |
| `src/components/coss/select.tsx:7-11` | `ChevronDownIcon, ChevronsUpDownIcon, ChevronUpIcon` | `CaretDown, CaretUpDown, CaretUp` |

- Phosphor import convention (`src/lib/icons.tsx:2-15`): named imports from
  `"@phosphor-icons/react"`, e.g. `import { CaretLeft, Check } from "@phosphor-icons/react";`.
- These icons are rendered with a Tailwind size/utility className (e.g. `className="size-4"`)
  and sometimes `animate-spin` (spinner). Phosphor icons forward `className` to the
  underlying `<svg>`, so the existing classNames keep controlling size/animation. **Keep the
  JSX usage identical** — only the imported component name changes (`<XIcon …/>` → `<X …/>`).
- `vite.config.ts:50` lists `lucide-react` in the `icons` manualChunk rule; once lucide is
  gone, drop the `lucide-react` clause there.
- `package.json` dependency: `"lucide-react": "^1.16.0"`.

### Step 1: Confirm the Phosphor names exist

Verify each replacement glyph is exported by the installed package:
`node -e "const p=require('@phosphor-icons/react'); ['CaretLeft','CaretRight','CaretDown','CaretUp','CaretUpDown','MagnifyingGlass','Check','CalendarBlank','X','CircleNotch'].forEach(n=>console.log(n, n in p))"`

**Verify**: every name prints `true`. If any prints `false`, STOP and report which one
(the package version may use a different name).

### Step 2: Swap imports + JSX in the 6 files

For each file in the table: change the `from "lucide-react"` import to the Phosphor
equivalents from `"@phosphor-icons/react"`, and rename the components at their JSX use
sites (e.g. `<ChevronLeftIcon className="size-4" />` → `<CaretLeft className="size-4" />`).
Keep every prop and className exactly as-is. The spinner (`coss/spinner.tsx`) keeps its
`animate-spin` className on `<CircleNotch … />`.

**Verify**: `grep -rn "lucide-react" src` → no matches. `npx tsc --noEmit` → exit 0.

### Step 3: Remove the dependency and the bundler clause

- In `vite.config.ts:50`, change the icons-chunk rule to reference only Phosphor:
  `if (id.includes("node_modules/@phosphor-icons/")) return "icons";` (drop the
  `|| id.includes("node_modules/lucide-react/")`).
- Remove `"lucide-react": "^1.16.0"` from `package.json` dependencies.
- Run `npm install` to update the lockfile.

**Verify**: `npm run build` → exit 0. `grep -rn "lucide-react" package.json vite.config.ts` →
no matches.

### Step 4: MANDATORY visual check

3. Any dialog → the close (X) button top-right (`dialog`).
4. Any `coss` Select dropdown → the caret/up-down indicators (`select`).
