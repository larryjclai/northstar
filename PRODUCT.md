# Product

Northstar is a local-first finance operating system for individual investors and households. It combines investment tracking, cash-flow tracking, FX-aware net worth, and household sharing while keeping readable financial data on trusted devices.

## Principles

1. Local-first before cloud convenience.
2. Privacy is a product feature, not only a policy.
3. Financial calculations must be explainable and testable.
4. Household sharing should not collapse personal privacy.
5. Market data providers must be replaceable.

## Packaging

The app uses Tauri 2 as the shell for desktop and mobile. The product UI is React/TypeScript so the same application surface can run across macOS, Windows, Linux, iOS, Android, and a browser dev shell.

## Connect

Connect adds sync and sharing without making the server a readable finance database. Account login identifies the user; trusted-device approval or a Recovery Kit unlocks the vault.
