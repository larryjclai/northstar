## How to sign

You do **not** sign this file directly. When You open a pull request, the CLA-assistant bot
will comment asking You to confirm agreement. Replying to that bot comment with the required
phrase records Your signature (name + GitHub username + timestamp) in the Project's signatures
store. Signing is **one-time** — it covers all Your future Contributions to the Project.

For an **entity / corporate** signature, contact the Project Owner so the authorized signatory
can be recorded.
